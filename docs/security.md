# Security Approach

- RDS is private and encrypted at rest.
- Application workloads run in private subnets.
- The ALB is the public entry point.
- Security groups allow only required application/database paths.
- PostgreSQL credentials are generated by Secrets Manager.
- ECS injects individual secret values into the backend task instead of storing credentials in source code.
- GitHub Actions uses OIDC rather than long-lived AWS access keys.
- ECR image scanning is enabled on push and image tags are immutable.
- IAM follows least privilege for the ECS task and GitHub Actions roles.
- Environment files containing real credentials are excluded by `.gitignore`.
